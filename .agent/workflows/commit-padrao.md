---
description: Realizar um commit seguindo o padrão de tipos em PT-BR
---

Para realizar um commit, utilize o comando `git commit -m "<tipo>: <mensagem>"` seguindo a tabela abaixo:

| Tipo | Quando usar |
| :--- | :--- |
| **feat** | Nova funcionalidade |
| **fix** | Correção de bug |
| **docs** | Alteração em documentação |
| **style** | Formatação, espaços, ponto e vírgula (sem mudar lógica) |
| **refactor** | Refatoração sem alterar comportamento |
| **test** | Adição ou ajuste de testes |
| **chore** | Tarefas de manutenção (build, deps, configs) |
| **perf** | Melhoria de performance |
| **ci** | Mudanças em CI/CD |
| **build** | Alterações no processo de build |

**Exemplo:**
`git commit -m "feat: adiciona motor de busca"`
